# Data

The dataset is **not included** in this repository. Download it from Kaggle:

**[Telecom churn (cell2cell) — Kaggle](https://www.kaggle.com/datasets/jpacse/datasets-for-churn-telecom)**

Place these two files in this folder:

```
data/
├── cell2celltrain.csv     # 51,047 customers, 58 columns, includes the Churn label
└── cell2cellholdout.csv   # 20,000 customers, same columns, Churn label empty
```

The data was originally compiled by the Teradata Center for Customer Relationship Management
at Duke University and used in the churn modelling tournament described by Neslin et al. (2006).
